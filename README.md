## 🚀 Tasks Summary

### 🟢 Level 1: Basic Tasks
- **Task 1: String Reversal** - Reverses user input text using string slicing.
- **Task 2: Temperature Conversion** - Converts temperatures between Celsius and Fahrenheit.
- **Task 3: Email Validator** - Validates email format using regex patterns.
- **Task 4: Calculator Program** - Performs basic arithmetic operations (`+`, `-`, `*`, `/`, `%`).
- **Task 5: Palindrome Checker** - Validates whether a given string is a palindrome.

### 🟡 Level 2: Intermediate Tasks
- **Task 1: Guessing Game** - Number guessing game between 1 and 100 with interactive hints.
- **Task 2: Number Guesser** - Random number guesser with custom user-defined range.
- **Task 3: Password Strength Checker** - Evaluates password complexity (Length, Case, Numbers, Symbols).
- **Task 4: Fibonacci Sequence** - Generates the Fibonacci sequence up to $N$ terms.
- **Task 5: File Word Counter** - Parses a text file, counts word frequencies, and displays sorted results.

### 🔴 Level 3: Advanced Tasks
- **Task 1: Web Scraper** - Extracts book details (Titles & Prices) from `books.toscrape.com` using `requests` & `BeautifulSoup`.
- **Task 2: Data Visualization Tool** - Interactive web interface built with Streamlit, Plotly, Pandas, and Seaborn for CSV data plotting.
- **Task 3: Automated File Organizer** - Script to automatically sort files into specific directories (`Images`, `Documents`, `Media`, `Code`).
